# Посмотри в окно

Учебный проект представляет собой интерактивную веб-страницу с подборкой видео из разных городов в разное время суток.

## Функциональность

- Отображение карточек с видео.
- Переключение основного видео при клике на карточку.
- Фильтрация видео по городу и времени суток через форму поиска.
- Кнопка «Показать еще».
- Отображение прелоадеров во время загрузки данных.
- Обработка ошибок (вывод сообщения, если видео не найдены или произошла ошибка сети).

## Технологии

- HTML5
- CSS3
- JavaScript

## Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/mayy1717/posmotri-v-okno-fd
2. Перейдите в папку проекта.
3. Откройте файл `index.html` в браузере или запустите его через Live Server в VS Code.

## Структура проекта

- `index.html` — основная разметка страницы и шаблоны.
- `styles/` — файлы стилей (`style.css`, `preloader.css`, `error.css`).
- `scripts/` — логика работы приложения (`script.js`).
- `fonts/` — шрифты и стили для них.
